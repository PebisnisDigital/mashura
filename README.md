**Status: Sprint 0 — dokumentasi selesai untuk ditinjau; Sprint 1 belum dimulai.** Belum ada aplikasi, migration yang dijalankan, deployment, atau project Supabase/Vercel yang dibuat. Tidak menggunakan resource BADAI.
